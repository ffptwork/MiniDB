# MiniDB.Tests

Тести на xUnit для Core, JSON-сховища, REST API, desktop API-клієнта та логіки інтерфейсу. Проєкт має посилання на Core, Server і Desktop та ціль net10.0-windows для перевірки WPF-проєкту.

Файлові й API-тести використовують тимчасові папки. Для HTTP-перевірок запускається Kestrel на випадковому локальному порту. Тести MiniDbApiClient і ViewModels підставляють HttpMessageHandler і не звертаються до мережі. Перевіряються вибір бази й таблиці, підготовка даних для DataGrid і діалогів, пошук, стан завантаження та повідомлення про помилки. Папка застосунку `data` не використовується.

Запуск із кореня проєкту: `.\dotnet.ps1 test MiniDB.sln`.
