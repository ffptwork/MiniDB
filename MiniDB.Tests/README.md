# MiniDB.Tests

Тести на xUnit для типів даних, моделей, валідаторів, пошуку за шаблоном, JSON-сховища та REST API. Є посилання на Core та Server.

Файлові й API-тести використовують окремі тимчасові папки. Для HTTP-перевірок запускається Kestrel на випадковому локальному порту. Сервер зупиняється, а файли видаляються після кожного тесту; папка застосунку `data` не використовується.

Запуск із кореня проєкту: `.\dotnet.ps1 test MiniDB.Tests\MiniDB.Tests.csproj`.
