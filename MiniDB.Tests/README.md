# MiniDB.Tests

Тести на xUnit для Core, JSON-сховища, REST API, desktop API-клієнта та логіки інтерфейсу. Проєкт має посилання на Core, Server і Desktop та ціль net10.0-windows для перевірки WPF-проєкту.

Залишено 21 ключовий тест: 12 для типів, валідації та пошуку Core, 2 для persistence, 6 для REST, health та імпорту/експорту і 1 для передачі файлу через Desktop. Варіації одного сценарію об'єднано; окремих тестів кожної кнопки немає.

Файлові й HTTP-тести використовують тимчасові папки. Для REST-перевірок запускається Kestrel на випадковому локальному порту. Desktop-тест викликає цей локальний сервер через MiniDbApiClient. Папка застосунку `data` не використовується.

Запуск із кореня проєкту: `.\dotnet.ps1 test MiniDB.sln`.
