# MiniDB.Tests

Тести на xUnit для Core, JSON-сховища, REST API та логіки Desktop/Web. Проєкт має посилання на Core, Server, Desktop і Web та ціль net10.0-windows для перевірки WPF-проєкту.

Усього 23 ключові тести: 12 для Core, 2 для persistence, 6 для REST, health та імпорту/експорту, 1 для Desktop і 2 для Web. Web перевіряє пошук, редагування за серверним індексом, перенесення бази та успішний запис при помилці оновлення. Окремих тестів кожної кнопки немає.

Файлові й HTTP-тести використовують тимчасові папки. Для REST-перевірок запускається Kestrel на випадковому локальному порту. Desktop-тест викликає цей локальний сервер через MiniDbApiClient. Папка застосунку `data` не використовується.

Запуск із кореня проєкту: `.\dotnet.ps1 test MiniDB.sln`.
