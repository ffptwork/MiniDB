# MiniDB.Tests

Тести на xUnit для типів даних, моделей, валідаторів, пошуку за шаблоном і JSON-сховища. Є посилання на Core та Server.

Файлові тести створюють окрему тимчасову папку й видаляють її після перевірки. Дані застосунку вони не використовують.

Запуск із кореня проєкту: `.\dotnet.ps1 test MiniDB.Tests\MiniDB.Tests.csproj`.
