# MiniDB.Server

Сервер на ASP.NET Core. Зараз реалізовано файлове сховище `DatabaseStorage`; контролери та API ще попереду.

Для JSON використовуються окремі DTO. Типи колонок зберігаються за назвами, а значення відновлюються через парсери Core. Приклад формату: [Demo.json](Persistence/Examples/Demo.json).

Папка з базами передається в конструктор сховища. Запис відбувається через тимчасовий файл із подальшою заміною основного. Імена файлів перевіряються, помилки читання та запису передаються викликачу.

Шлях до Railway Volume буде задано під час розгортання.
