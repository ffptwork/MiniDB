# MiniDB.Core

Ядро системи: бази, таблиці, колонки та рядки. Значення рядків зберігаються у відповідних типах, а зміни проходять перевірку.

Підтримуються `integer`, `real`, `char`, `string`, `color` (RGB) і `colorInvl` (інтервал кольорів). Фабрика відновлює тип за його назвою.

Імена й текстовий пошук враховують регістр. Для `string` і `char` символ `*` означає довільну послідовність символів; решта типів шукаються за точним значенням.

Схема задається до додавання рядків. Числа розбираються з десятковою крапкою. Ядро не залежить від WPF, серверного API чи JSON-сховища.
